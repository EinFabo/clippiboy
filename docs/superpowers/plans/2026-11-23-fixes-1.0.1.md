## Task 1: Capture survives display topology changes and graphics resets (151, 169)

PLAN 151 "Neuer Hinweis (2026-11-23)": WGC capture dies without `Closed` when the display topology changes (a DP
monitor drops out briefly, even a non-recorded one); `convert.rs` then repeats the last frame (often the lock screen).
- Pure `capture::fingerprint(&[CaptureTarget])` (sorted: device name, panel, x/y/w/h, primary) and `settled(prev, now)`
  (two equal readings, every screen has its identity) and `needs_restart(at_start, settled)`.
- Store the fingerprint at pipeline start (`pipeline.rs` before `wgc::start`). `watch_monitors` (`lib.rs` ~791) reads
  positions too and keeps a settled fingerprint; a watcher next to `watch_screen`: buffer running, no recording,
  session not locked, `needs_restart` → restart the pipeline, limited by `state::RestartBudget` against flicker; no
  double restart after unlock / display-on (compare against the fingerprint at start).
- Second line: a stall watchdog armed only by an event (topology, display on, unlock, wake): after 5 s without a new
  frame AND the foreground game window is on the recorded monitor (`MonitorFromWindow`) → restart. Pure `stalled(...)`
  in `state.rs` with tests (game on another screen → never; not armed → never; frames after the event → never).
- Graphics reset (169): add adapter LUIDs + driver version (DXGI) to the fingerprint; when they change, after settling,
  also recreate the banner and console windows (`overlay.rs`, `console.rs`).
- Logs: each settled topology (all screens), capture start (HMONITOR, device, rect, how found, lock state), `new=<n>`
  and "last new frame Xs ago" in the health line, a line on `Closed`, a reason on every restart.
- Tests as listed in PLAN 151 (incl. secondary screen gone/back → restart, order only → none, renumbered recorded
  screen → restart, mid-change reading → wait, flicker → budget).
